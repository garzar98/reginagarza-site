REGINA PORTFOLIO — EDITORIAL REDESIGN

FILES
index.html     Website content and structure
styles.css     Colors, typography, responsiveness, visual styling
script.js      Transparent navigation, mobile menu, reveal, parallax

TO PREVIEW
Open index.html in your browser. This works without a build step.
Internet access is required for Google Fonts and the two Unsplash photos.

BEFORE YOU PUBLISH
1. Replace YOUR_EMAIL@example.com in index.html with your real email.
2. Replace generic GitHub and LinkedIn URLs with your actual profiles.
3. Put your regina_resume.pdf beside index.html (or change its link).
4. Replace the two illustrative Unsplash images with your own chosen imagery if desired:
   hero: .hero-image in styles.css
   interlude: .image-break-bg in styles.css
5. Check descriptions of projects against their current status and add real project links/screenshots.
6. All project visuals are CSS mockups, not screenshots of completed products.

DESIGN DETAILS
Transparent-to-blurred navigation on scroll; image parallax effect;
scroll-triggered reveal animations; mobile nav; reduced-motion accessibility.

DEPLOYMENT
Upload index.html, styles.css, and script.js to the same web directory.
You can keep about.html and contact.html, or use this homepage's section anchors.
